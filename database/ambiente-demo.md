# Ambiente Demo - DirectOS

## Objetivo

Disponibilizar uma empresa fictícia para demonstração comercial do DirectOS.

## Acesso

URL:

https://directos-saas.onrender.com

Usuário:

demo@directos.com.br

Senha:

Demo@123

## Empresa

Nome:

DirectOS Demo

Segmento:

Informática / Assistência Técnica

## Dados disponíveis

O ambiente demo contém:

- Clientes fictícios
- Serviços fictícios
- Ordens de serviço em vários status
- Campos personalizados
- Recebimentos
- Relatórios operacionais
- Relatório financeiro
- Recibos

## Fluxo recomendado de demonstração

1. Fazer login com usuário demo
2. Abrir Dashboard
3. Mostrar Clientes
4. Mostrar Serviços
5. Mostrar Ordens de Serviço
6. Abrir uma OS concluída
7. Mostrar campos personalizados
8. Mostrar controle financeiro
9. Abrir recibo
10. Abrir relatório operacional
11. Abrir relatório financeiro
12. Exportar CSV

## Cuidados

- Não usar dados reais no ambiente demo
- Não divulgar senhas administrativas reais
- Não misturar dados de clientes reais com a empresa demo
- Validar periodicamente se os dados demo continuam íntegros

## Próximas melhorias

- Bloquear exclusões no usuário demo
- Criar botão ou script para restaurar dados demo
- Criar modo somente leitura para demonstração
